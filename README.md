# Formwork — JSON Studio

A client-side JSON formatter, validator, anonymiser, and mock-data generator — built entirely with HTML, CSS, and JavaScript. Nothing leaves your browser.

## Live Demo
[formwork-json-studio.vercel.app/](formwork-json-studio.vercel.app/)

## Features
- **Format** — prettify messy or minified JSON with proper indentation
- **Validate** — check JSON validity without altering your input
- **Friendly Errors** — plain-English explanations instead of cryptic stack traces
- **Auto-Fix** — one-click repair for common issues (missing commas, unclosed brackets)
- **Anonymise** — recursively scrub names, emails, and phone numbers from JSON
- **Mock ×100** — generate 100 randomized entries matching your JSON's shape, downloadable as a file
- **Live Analytics** — byte size, character count, max depth, array count, key/value pairs
- **Syntax Highlighting** — color-coded output via PrismJS
- **Themes** — light, slate, and dracula
- 100% client-side — no servers, no data ever leaves your browser

## Built With
- HTML, CSS, JavaScript (vanilla, no frameworks)
- [PrismJS](https://prismjs.com/) for syntax highlighting
